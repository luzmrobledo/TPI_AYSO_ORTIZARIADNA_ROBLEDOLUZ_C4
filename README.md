## Descripción

El trabajo analiza la seguridad de un servidor a partir del resultado de un escaneo de puertos con **Nmap**. Se plantea un caso **simulado**: una pequeña empresa ficticia con un equipo (`192.168.1.1`) que podría estar exponiendo más servicios de los necesarios. Las autoras actúan como consultoras: interpretan el escaneo, priorizan los riesgos y proponen un plan de protección.

> **Aclaración:** el caso se basa en el escaneo de ejemplo del apunte de la cátedra. No se realizaron escaneos sobre equipos reales. El resultado posterior al plan de protección es una proyección, no una medición.

## Objetivos

1. Explicar el funcionamiento de un escaneo de puertos con Nmap.
2. Interpretar el resultado de un escaneo (puertos abiertos, cerrados y filtrados).
3. Identificar y priorizar los riesgos detectados.
4. Proponer un plan de protección con comandos concretos.
